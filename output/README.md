# Output Directory

Final rendered video files will be saved here.

## Files

- `coffee_ad.mp4` - Final 30-second advertisement (1080p)
- `coffee_ad_draft.mp4` - Draft version for review
- `coffee_ad_social.mp4` - Optimized for social media
- `coffee_ad_vertical.mp4` - Vertical format (9:16) for Stories/Reels

## Specifications

| Format | Details |
|--------|----------|
| Codec | H.264 (mp4) |
| Resolution | 1920x1080 (1080p) |
| Frame Rate | 30 FPS |
| Bitrate | 5000 kbps |
| Audio | AAC, 128 kbps, Stereo |

## Export Formats

- **YouTube**: 1920x1080 MP4
- **Instagram**: 1080x1080 or 1080x1350 MP4
- **TikTok**: 1080x1920 MP4
- **TV**: 1920x1080 MP4
