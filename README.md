# Coffee Advertisement Video Project

A professional coffee advertisement video production project.

## Project Overview

This project contains all assets, scripts, and code needed to produce a high-quality coffee advertisement video.

## Directory Structure

```
├── scripts/           # Video scripts and voiceovers
├── storyboard/        # Storyboard images and descriptions
├── assets/            # Images, logos, and graphics
├── code/              # Video generation code
├── audio/             # Background music and sound effects
├── output/            # Final rendered videos
└── docs/              # Documentation and production notes
```

## Quick Start

1. Review the script in `scripts/`
2. Check the storyboard in `storyboard/`
3. Prepare assets in `assets/`
4. Run video generation using code in `code/`
5. Find output in `output/`

## Video Specifications

- **Duration**: 30 seconds
- **Format**: 1080p (1920x1080)
- **Frame Rate**: 30 FPS
- **Aspect Ratio**: 16:9
